# AI-agent-system
文件驱动的多Agent协作系统：写一句任务，AI自动拆解→调度→执行→完成

---

```markdown
# AI 多Agent协作系统

> 写一句话，AI自动拆解、调度、执行、完成。

## 它能做什么？

你只需要在指定文件里写一句任务描述，比如“分析D盘空间占用，生成清理建议”，系统就会自动完成：

1. 拆解任务 → 2. 生成指令 → 3. 调用执行层 → 4. 写入成果 → 5. 判断是否完成 → 6. 循环直到结束

全程不需要你手动复制任何内容、不需要你盯着终端。

## 系统架构（三层结构）

```

你写入任务目标
↓
决策层（DeepSeek API）→ 拆解任务，生成指令
↓
触发层（trigger.py）→ 监听文件变化，自动调用执行层
↓
执行层（Claude Code / Codex）→ 执行任务，写入成果
↓
决策层读取成果 → 判断是否完成 → 继续或结束

```

## 怎么用？

**1. 启动决策层和触发层**
```bash
python decision_agent.py   # 终端1
python trigger.py          # 终端2
```

2. 写入任务

在 0_决策层/当前任务目标.md 里写你想做的事，例如：

```
分析当前项目根目录下的文件结构，生成目录树
```

3. 等结果

系统会自动完成，结果写在 1_Codex/工作成果.md 或 2_ClaudeCode/工作成果.md 里。

文件夹结构

```
项目根目录/
├── 0_决策层/          ← 任务目标、指令文件、决策日志
├── 1_Codex/           ← Codex 工作区
├── 2_ClaudeCode/      ← Claude Code 工作区
├── 3_共享参考/        ← 所有Agent只读共享
├── decision_agent.py  ← 决策层脚本
└── trigger.py         ← 触发层脚本
```

依赖

· Python 3
· DeepSeek API Key
· Claude Code CLI 或 Codex CLI（至少一个）

许可证

MIT

```
